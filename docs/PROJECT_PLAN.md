# Bashai Fera — Project Plan

## Vision
A lightweight, cinematic browser game inspired by everyday journeys through Dhaka, combining road-survival gameplay with a respectful road-safety memorial.

## Initial Priorities
1. Build a playable 3D road prototype.
2. Implement responsive desktop and mobile controls.
3. Add traffic hazards and fair collision mechanics.
4. Create route selection for real Dhaka journeys.
5. Develop cinematic transitions and sound design.
6. Integrate verified road-accident memorial cases.
7. Optimise performance and publish the game.

## Development Principles
- Build and test one feature at a time.
- Keep the game lightweight.
- Preserve working versions in Git.
- Verify facts and respect victims' dignity.
- Use properly licensed assets and map data.
